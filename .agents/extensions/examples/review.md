# review（範例：複製到 `.agents/extensions/review.md` 後改）

自審與 reviewer 的 Standards 軸，除了通用檢查外，再加下列專案專屬項目。

## 檢查項

- [ ] 新的對外介面（`<API / CLI / 事件>`）有更新 `<文件路徑>`
- [ ] 改了 `<schema 目錄>/` 就有對應 migration，且可回滾
- [ ] 錯誤處理走 `<專案的錯誤處理慣例>`，不直接吞例外
- [ ] 新增設定項有預設值，並寫進 `<設定文件路徑>`
- [ ] 不在 `<目錄>/` 之外直接讀環境變數，統一走 `<設定模組>`
- [ ] log 不含 `<敏感欄位，例如 token、個資>`
- [ ] 測試：bug fix 附能重現問題的測試

## 常見過嚴意見（不要提）

- `<檔案或目錄>` 為產生檔，不審排版與命名。
- `<某種寫法>` 是刻意保留的相容寫法，見 `<文件路徑>`，不要求改掉。
- 僅風格偏好、`<formatter / linter>` 沒擋的項目，不當 blocker。
